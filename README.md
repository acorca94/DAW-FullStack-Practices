# 💻 Prácticas y Ejercicios de Desarrollo de Software (DAW)

Colección de ejercicios prácticos y proyectos pequeños desarrollados durante el Grado Superior en Desarrollo de Aplicaciones Web (DAW).

-------------------------------------------------------------------------------------------------------------------------

## 🛠️ Tecnologías y Módulos

### ☕ Java & Programación Orientada a Objetos (POO)
* **Conceptos:** POO (Herencia, Polimorfismo, Encapsulamiento), Estructuras de control, Manejo de Excepciones y Ficheros.
* **Bases de Datos:** Conexión y persistencia mediante JDBC / BDD relacionales.
* **Cursos & Prácticas:** Prácticas académicas del grado DAW.

### 🐍 Python
* **Conceptos:** Manipulación de listas, estructuras avanzadas, POO básica y algoritmos.

### 🗄️ Bases de Datos
* **Conceptos:** Conexiones JDBC, diseño de modelos relacionales y consultas SQL.
